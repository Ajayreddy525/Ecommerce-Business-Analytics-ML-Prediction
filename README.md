# E-Commerce Business Analytics & Machine Learning Prediction

An end-to-end E-Commerce Analytics and Machine Learning project combining Python, SQL, LightGBM, Excel, and Power BI to explore business performance and generate predictive insights.

## Project Overview

This project focuses on analyzing e-commerce data, identifying business trends, understanding customer behaviour, and developing machine learning prediction workflows.

It includes 10 Power BI report pages covering business analytics and machine learning predictions.
